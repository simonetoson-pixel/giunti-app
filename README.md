# Giunti — app di rilievo

Web app installabile per il rilievo dei giunti di dilatazione sulle tratte
autostradali in gestione.

Qui dentro c'è solo l'interfaccia. I dati — censimento, rilievi, foto — stanno
su Supabase e sono accessibili solo dopo l'accesso: aprire questo indirizzo
senza credenziali non mostra nulla.
